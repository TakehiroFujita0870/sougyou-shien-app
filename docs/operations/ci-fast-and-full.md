# CIの確認範囲

Pull requestとmainへの反映では、現行Nebulaの画面テスト、アクセシビリティ検査、画面ビルド、Pythonテストを実行する。GitHubの手動実行も同じ確認を行う。旧会話画面、Storybook、PDF・DOCX出力の専用検査は製品から廃止した。

画面の配置や操作を変えた場合は、CIに加えてPCの1280×720でホーム、グラフ、サービス管理を実際に確認する。通常の保存先を止める再起動試験や速度比較を、旧資産の削除だけを理由に繰り返さない。

CI失敗を残したままmainに反映しない。ローカルでは意味のある一まとまりを検査してからcommit・push・pull requestを行い、毎回の小さな編集ではGitHubを操作しない。

実行する検査の正本は[CI設定](../../.github/workflows/ci.yml)。
