# AIモデルとAPIのライフサイクル

最終検証日: 2026-08-09

## 目的

Dots.が複数のAIプロバイダーを安全に扱い、モデルの追加・価格変更・廃止に追随できるようにする。本書はモデル選択、APIキー、更新検知、評価、切り戻しの正本である。

## 初回リリースの境界

| プラン | 初回リリース | モデル体験 |
| --- | --- | --- |
| Free | 対象 | 軽量モデル固定、Thinkingなし、基本対話とアイデアストック |
| Standard（月額980円） | 対象 | 利用可能モデルをユーザーが選択。既定は `gpt-5.6-terra` |
| Pro（月額2,980円） | 対象外 | 利用・原価データ蓄積後に、自動深掘りとメールレポートを別仕様で判断 |

Pro向けのスケジュール実行、メール送信、外部サービス契約は初回リリースへ含めない。

## 開発時の互換対象

Claude APIとの接続実装では、次のモデルIDを互換対象とする。

| 表示名 | Claude API model ID | 主な開発用途 |
| --- | --- | --- |
| Claude Opus 5 | `claude-opus-5` | 複雑な分析と高品質評価 |
| Claude Sonnet 5 | `claude-sonnet-5` | 標準対話と分析 |
| Claude Haiku 4.5 | `claude-haiku-4-5-20251001` | 低遅延・低コスト処理 |

製品コードは表示名やモデルIDで分岐せず、論理キー、プロバイダー、能力フラグを持つモデルカタログを参照する。将来のカタログは最低限、`logical_key`、`provider`、`model_id`、`plans`、`reasoning_modes`、`capabilities`、`cost_class`、`enabled`、`is_default`を持つ。

## APIキーと実データ

- Claude APIを実際に呼び出す直前に、タケさんがClaude Consoleで開発用ワークスペースとAPIキーを作成する。
- ローカル開発ではキーを `ANTHROPIC_API_KEY` 環境変数から読み、Git管理ファイル、ログ、テストデータへ保存しない。
- OpenAI接続を有効にするときは、同様に `OPENAI_API_KEY` を秘密管理し、製品コードへ埋め込まない。
- APIキー作成、クレジット購入又は課金開始、実ユーザーのプロフィール又はアイデア送信はCEO決裁事項とする。
- キーがない開発環境では、固定レスポンスを返すFakeプロバイダーでUIと契約テストを実行可能にする。
- 本番では可能なら短期資格情報又は秘密管理基盤を使い、キーの有効期限、ローテーション、失効手順を運用文書へ記録する。

APIキーの値をIssue、PR、チャット、スクリーンショットへ貼らない。作成が必要になった時点で、タケさんにはConsole上の操作だけを依頼する。

## モデル更新の将来自動化

自動化は次の順序を守る。

1. 公式モデル一覧、Models API、廃止予定、価格表を定期確認する。
2. 現行カタログとの差分を、追加・変更・廃止予定に分類する。
3. 変更モデルを代表プロンプトの評価セットで比較する。
4. 品質、応答時間、概算原価、機能差、破壊的変更をレポートする。
5. モデルカタログと本書の更新PRを自動作成する。
6. CIと人間レビュー後にだけマージする。

自動化はモデルを発見してPRを作るところまでとし、次を自動実行しない。

- 本番の既定モデルを無審査で変更する。
- ユーザーの利用可能モデルを予告なく削除する。
- 評価を通していない新モデルへ既存会話を移行する。
- 価格上昇を伴う変更を自動承認する。

## 切り戻し

- 本番で使用するモデルIDとカタログ版を実行記録へ残す。
- 更新PRは直前モデルIDと設定を保持し、設定変更だけで切り戻せるようにする。
- 品質低下、エラー率上昇、原価超過を検出した場合は新規実行を直前モデルへ戻す。進行中の会話を途中で別モデルへ切り替えない。
- 廃止期限が迫る場合も、評価未完了なら対象機能を停止し、未評価モデルへ自動移行しない。

## 更新時の受入条件

- 公式なモデルID、利用可否、価格、廃止予定を確認している。
- FreeとStandardのプラン境界が変わっていない、又は変更理由がPRにある。
- 代表プロンプトで旧モデルと新モデルの品質・速度・概算原価を比較している。
- APIキー又は実ユーザーデータをテストに使用していない。
- 切り戻し先と操作手順がPRに記載されている。
