# 全体計画の正式版同期

## 要望 / ゴール / 成功指標

要望: 利用者が承認した下書き保存、調査後の意味分割、根拠付き再利用、PC専用画面、接続整理の全体計画を正式版へ届ける。
ゴール: 実装全体計画を現行要件に揃え、配送済み・実接続確認済み・未完了を区別する。
成功指標: 全体の完成条件を維持した文書差分だけを独立レビューし、mainへ反映後もMVP未完了と明記する。

## ユーザーストーリーと受け入れ条件

As a 本人, I want 全体計画と残作業を正しい文書で確認したい, so that 接続成功だけを完成と取り違えない。
Given: 承認された現行計画と、PR #246–259・実接続の検査記録がある。
When: 全体計画と配送順を正式版へ同期する。
Then: 下書き→内部検索→許諾済み調査→8観点概要→根拠付き意味分割→別会話再利用の順序と、代表5会話・訂正・安全性・起動・登録整理の未了条件を保持する。本文にあるローカル文書リンクは解決でき、未配送資料はその状態を明示する。

## 質問リスト

なし。利用者の既承認要件の記録であり、新しい公開・費用・データ操作を行わない。

- 旧phaseの再実行、速度比較、全MVP完成の宣言。

現行要件・未了条件を先に正式化する。実装済み分だけに完成条件を縮小する案は利用者の全体ゴールを失うため却下する。未配送資料への壊れたリンクは貼らず、名前と未配送状態を明記し、資料配送時にリンクへ戻す。
