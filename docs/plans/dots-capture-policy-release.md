# Dotsの会話保存手順

## 目的と受け入れ条件

- 下書きは調査前に保存・検索できる。正式なIdea関係は調査後の全8観点概要と根拠に基づく。
- 外部調査の目的・範囲・予算・期限の許諾を先に得る。取消・失敗・追加試行を成功と偽らない。
- 根拠IDを捏造せず、現在の概要/章/共有可能Evidenceを使い、訂正は旧関係参照を残す。
- 本人専用の既存プラグインと通常接続を保持し、日本語説明・Takehiro Fujita・指定白背景アイコンを採用する。
- 同一記録の重複を避け、書き込み成功後にのみ保存済みと伝える。接続に未反映の機能は実行したと主張しない。

## 検査と範囲

1. portable/legacy manifest、接続ID、アイコン実体、skill frontmatterと9項目を照合する。
2. 登録版1.0.5のsource read-backを比較する。旧1.0.4からの変更は手順とversionのみで、PRIVATE/作者/接続/アイコン参照を保持した。
3. 実ChatGPT会話、スマホ書き込み、調査から別会話再利用は別途MVP受入で確認する。この配布物だけで完了を宣言しない。

DB/APIの実装変更・資格情報・実データは含まない。旧手順への巻き戻しは前版を基準に新しいversionとして登録する。削除や公開範囲変更はしない。
