# Issue #73 AI広報の製品UI撤去 計画

最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標

要望: AI広報をKadode製品UIから撤去する。

ゴール: 製品のナビゲーションと実行可能なコンポーネントからAI広報を除き、開発運用の仕様文書だけを残す。

成功指標: `src/` にAI広報の製品UI・repository・Storybook story・テストがなく、通常のAppにAI広報のナビゲーションが表示されない。

## ユーザーストーリーと受け入れ条件

### US-73-1

As a Kadode利用者, I want 製品ワークスペースからAI広報を見ない, so that 初回リリースの対象機能だけを操作できる。

Given: 通常のKadode Appを開いている
When: ワークスペースナビゲーションを確認する
Then: AI広報のボタン、画面遷移、下書き操作が存在しない。

### US-73-2

As a 開発担当者, I want AI広報の運用方針を文書だけで参照したい, so that X投稿や外部送信を製品に復活させない。

Given: リポジトリを検索する
When: AI広報の実装資産を確認する
Then: `docs/spec/ai-pr-draft-approval-flow.md` は残り、`src/` のAI広報UI、repository、story、テストは存在しない。
