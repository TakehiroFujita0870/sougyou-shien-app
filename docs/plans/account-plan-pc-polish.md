# PC Account・Plan polish 計画

最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標

### 要望原文

> PC版のAccountとPlanを仕上げる。閉じたアカウントトリガーはアバター、表示名、Freeバッジ、シェブロンだけにする。展開時はレイアウトを動かさないメニューにする。Planは料金と利用枠を比較し、モデル設定、外部課金、開発環境の説明を表示しない。Proは月額2,980円の準備中表示にする。

### ゴール

PC利用者がサイドバー下部から必要なアカウント操作へ移動でき、設定画面でFree、Standard、Pro準備中を料金と利用枠で比較できる。

### 成功指標

- 1440x900で閉じたトリガーとメニューがサイドバーの幅を変えない。
- キーボードでメニューを開き、Escapeで閉じ、目的のメニュー項目へ移動できる。
- Plan画面にモデル、Thinking Effort、外部課金、開発環境を示す文言がない。

## ユーザーストーリーと受け入れ条件

### US-01 アカウント操作

As a PC利用者, I want コンパクトなアカウント入口を開きたい, so that 画面を圧迫せずに設定へ移動できる。

Given: 1440x900のサイドバー下部にアカウントトリガーが表示されている

When: トリガーをクリックまたはキーボードで起動する

Then: アバター、表示名、Freeバッジ、シェブロンは閉じたまま保たれ、アンカーされたメニューに情報、プランと利用状況、設定、ヘルプ・ショートカット、ログアウトが表示される

### US-02 キーボード利用者

As a キーボード利用者, I want アカウントメニューを閉じたい, so that 操作対象を見失わずに作業へ戻れる。

Given: アカウントメニューが開いている

When: Escapeを押す

Then: メニューが閉じ、フォーカスがアカウントトリガーへ戻る

### US-03 プラン比較

As a 利用者, I want 料金と利用枠でプランを比較したい, so that 自分に合う利用範囲を把握できる。

Given: プランと利用状況を開いている

When: Free、Standard、Proのカードを確認する

Then: FreeとStandardは料金と月間利用枠を比較でき、Proは月額2,980円と準備中状態を示し、モデル設定や外部課金の説明は表示されない
