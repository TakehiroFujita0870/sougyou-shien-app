# 訂正した関係の再利用

## 問題と受け入れ条件

通常の保存先で、根拠付きの関係の訂正は保存されたが、訂正後の関係を取得・検索できなかった。履歴への参照にも現行記録の判定を適用し、正しい過去の関係を拒否していた。

- 現行の訂正関係は取得・検索できる。
- 直前の履歴は同じ所有者・関係系列・端点・意味で、連続する版だけを許容する。
- 履歴そのものは検索候補や公開端点にしない。
- 現行端点、出典、共有範囲の既存検査は維持する。

## 検査と戻し方

失敗する再現テストを先に追加し、限定した履歴参照の処理で修正する。他人の履歴、別系列、不連続な版、別端点は拒否する。データの変更は不要。戻す場合はこの読取修正だけを取り消す。
