# Founder Graph live read UI 計画

最終検証日: 2026-09-23

## 要望 / ゴール / 成功指標

### 要望

保存済みのFounder Graphを、既存の安全な読み取り口から画面へ読み込み、停止時も利用者が再試行できるようにする。

### ゴール

画面の表示部品を、利用者が明示的に渡したローカル読み取り窓口へ接続できるようにする。通常起動は従来の安全な空表示を保ち、ホストが接続先を明示した場合だけGraph画面へ接続する。Home、Project、Knowledgeの動作は変えない。

### 成功指標

- 読み込み中、データなし、停止中、読込失敗、データありを画面で区別できる。
- 停止中または読込失敗時、再試行ボタンで同じ検索をもう一度実行できる。
- 画面へ渡すのは既存の安全な読み取り結果だけで、原文や連絡先を新たに扱わない。
- 接続先と本人確認用の値は呼び出し側が明示し、画面の読み込みだけで外部接続しない。

## ユーザーストーリーと受け入れ条件

### US-LIVE-1 保存済み情報の表示

As a local founder, I want to load matching Founder Graph information from my running local Dots service, so that I can inspect saved information in the Graph screen.

Given: ローカルDotsが起動し、安全な検索結果を返す。
When: 画面用の読み取り部品が検索語と明示した接続先を受け取る。
Then: 読み込み中の表示の後、結果カードだけが表示される。

### US-LIVE-2 停止時の再試行

As a local founder, I want to retry after Dots is stopped or temporarily unavailable, so that I can continue without mistaking previously displayed information for current information.

Given: 読み取り窓口が停止中を返す、または接続できない。
When: 画面がその結果を受け取る。
Then: 結果カードを消して停止中の説明と再試行ボタンを表示する。

Given: 停止後にローカルDotsが起動している。
When: 利用者が再試行を選ぶ。
Then: 同じ検索語で再度読み込み、成功時は新しい結果だけを表示する。

## スコープ外

- 共通見た目、既存の4画面導線の変更。`App.jsx`は明示クライアントを受け取る接続点だけを追加する。
- 接続先の自動探索、認証情報の保存、外部AI・外部ネットワークへの接続。
- 検索語の入力欄、無制限一覧、書き込み、訂正、削除、人物統合。

## ADR

| 判断 | 選択と理由 | 却下案と理由 | 結果 |
| --- | --- | --- | --- |
| ADR-LIVE-1 接続方法 | 既存のローカル読み取り口を、呼び出し側から明示して渡す | 画面の起動時に接続先や本人確認値を自動取得する案は、停止中の誤接続と情報流出の境界を曖昧にするため却下 | 実機起動後だけ接続でき、部品単位で安全に検証できる |
| ADR-LIVE-2 停止の扱い | 停止中と通常の失敗を分け、どちらも古い結果を消して再試行可能にする | 古い結果を残す案は、今読めている情報と誤認させるため却下 | 利用者は今の状態を判断できる |
