# 直接見つかった記録にも意味関係を返す

通常保存先の同じ合成資料を検索すると、関係の両端は直接一致で取得される一方、関係探索の点数が直接一致を上回らないため、根拠付き関係の経路が失われる。保存された関係の欠落ではなく、検索順位と経路保持の結合が原因である。

## 受け入れ条件

- 直接一致の順位・点数・件数制限を変えない。
- 実在する現行の検証済み関係を、別の根拠経路として保持する。
- 経路は既存の1〜2段階に限定し、循環と架空の接続を作らない。
- 所有者・共有範囲・現行端点・現行概要・根拠の検査を維持する。
- 両端が直接一致する合成検索で、現行関係の識別子・方向・出典を返し、無関係な直接一致や旧版には経路を付けない。

速度比較・モデル変更・新規調査は行わない。検索の読取コードと回帰テストだけで独立して配送し、同じ保存記録で一度確認する。取消は読取コードだけで行い、データは変更しない。
