# Dots. Founder Graph 製品方針

Dots. は本人一人が使う、創業のためのローカル知識グラフである。ChatGPTで話したアイデア、知識・経験、人脈、調査の根拠を蓄積し、次の事業仮説へ再利用する。Dots. 自身は別のAIチャットや調査通知を作らず、保存・検索・構造化・出典管理へ集中する。

保存形式と関係の契約は[データモデル](founder-graph-data-model.md)、完成条件と実装の進め方は[全体計画](dots-implementation-master-plan.md)、現在の反映・検証状態は[現況](../operations/dots-current-status.json)を正本とする。ピボット前と完了した個別計画の経緯はGit・PR履歴で確認する。

## 製品の境界

- 単独利用・ローカルNeo4jが前提。組織共有、課金、一般公開、公開マーケット配布は初期対象外。Dots. 停止中はChatGPTからアクセスできなくてよい。
- ChatGPTが会話、アイデア候補の検知、調査の提案・実行・通知、追加質問への対応を担う。Dots. は正本の記録と安全な検索結果を返す。会話全体の無断自動収集は前提にしない。
- 未調査のアイデアも下書きとして保存・検索する。新規または再利用した具体的な未調査案には、同じ会話で調査を一度だけ提案する。単なる一覧や検索結果の閲覧では提案しない。
- フル調査は目的、範囲、外部へ渡す情報、試行予算、有効期限について本人の許諾を得てから始める。同一範囲で複数回調査でき、各試行と改訂は履歴を残す。
- 調査結果には実際に使った資料の題名・URLと、どの主張を支えるかを残す。調査していないURLを補わない。調査完了後の概要を意味分割し、出典の保存とともに同じChatGPTが追加承諾なしで知識グラフを整理する。
- 関係は「似た文章」や改訂履歴だけで確定しない。アイデア、資産、顧客課題、提供価値などの関係に根拠、推測・確認状態、元の概要版を付ける。訂正時は旧関係を現行検索から外し、履歴として保持する。人物の名寄せ確定や破壊的変更は別途確認する。
- Dots. 内では全体を検索できるが、ChatGPTへ返すのは共有可能な項目だけ。連絡先・非公開メモ・住所などは既定で返さず、公開調査へも渡さない。未指定の公開区分は非公開扱いとする。通常の共有可能な検索を呼出ごとに承認させない。
- 内容の抽出・整理は初期値としてLunaを使う。検索の埋め込みと再順位付けには、固定版のSentence Transformers対応・多言語ローカルモデルを使う。費用が問題になれば抽出側もローカルモデルへ差し替える。

## 利用の流れ

1. 本人がChatGPTでアイデアを話す。ChatGPTはDots. を使って下書きを保存し、関連する過去案・資産・資料を検索する。
2. 具体的な未調査案なら一度だけ調査を提案する。本人が許諾した範囲でChatGPTが外部情報も調べる。拒否・中断されても下書きは残る。
3. ChatGPTが8観点の概要をまとめ、実際の出典と根拠をDots. に保存する。同時に意味関係と分類を整理する。根拠のない推測を事実として扱わない。
4. 本人の追加質問や訂正に応じて調査と概要を改訂する。別会話では現行の概要・関係・出典を検索でき、過去の版も追跡できる。

## 画面

PC向けにホーム、グラフ、サービス管理の3画面を提供する。確認する基準は1280×720であり、スマートフォン向け管理画面は作らない。スマートフォンのChatGPTからのDots. 利用は別の接続経路として扱う。

- ホームは「アイデア」「あなたのアセット」「人的ネットワーク」のタブ。アイデアは題名と調査状態から概要を開ける。アセットは自己紹介専用欄や既定カテゴリー見出しを設けず、同じ粒度の一覧と個別編集にする。人的ネットワークの詳細登録は後続の対象。
- グラフは意味関係を中心に描き、関係の根拠へたどれるようにする。改訂・保存形式の内部ノードを通常の主役にしない。
- サービス管理は保存先、画面、ChatGPT接続の状態を示し、停止・再開を提供する。画面を閉じても保存先は止めない。

## 事業評価の8観点

| 章 | 名称 | 確認すること |
| --- | --- | --- |
| 0 | エグゼクティブサマリー | 仮説、現時点の評価、最大の未確認事項、次の判断 |
| 1 | ビジネスモデル | 顧客、課題、提供物、販売経路、何を売るか |
| 2 | 顧客とマーケットサイズ | 顧客区分、需要根拠、市場規模の定義・式・前提 |
| 3 | 収益モデル | 価格、数量、費用、獲得費用、損益分岐、資金繰り |
| 4 | 競争優位性 | 競合・代替、他社が実行しない理由、模倣困難性 |
| 5 | 実現可能性 | 技術、運用、販売、法務、資金、時間、本人の資産 |
| 6 | リスク・撤退ライン | 主要リスク、先行指標、継続・停止条件 |
| 7 | リスクミニマムなロードマップ | 可逆な検証順序、費用・時間上限、各段階の判断 |

各観点で、事実、AI推論、未確認事項、本人判断を分ける。市場・財務の数値は式、単位、期間、入力値、前提とともに保存する。全文の製本はDots. の必須機能ではなく、再利用に必要な概要・根拠・改訂履歴を保持する。

## データと安全

アイデア、資産、調査資料は並列の領域であり、抽象度の階層ではない。人物・組織、主張・根拠、分類、調査試行、判断は横断して結び付ける。ノードとエッジの実際の保存単位、改訂、根拠、検索投影は[データモデル](founder-graph-data-model.md)に従う。

AGENTS.mdやSkillはファイル本体を正本とし、Dots. は所在、対象範囲、変更の印、要約、関連情報を柔らかく管理する。秘密値を取り込まず、ファイルがなくなったら過去版を現行ルールと誤認しない。Dots. から指示ファイルを自動編集しない。

保存・検索・削除・復旧では、本人の通常データを検査のために消さない。可逆な操作と履歴を優先し、物理削除、外部公開、課金、契約、第三者への送信を無断で行わない。
