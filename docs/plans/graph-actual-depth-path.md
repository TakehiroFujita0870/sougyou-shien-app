# 実際の階層を奥行きでたどる

広い分類から中間分類を経て具体的な記録へ至る実際の経路を画面へ渡す。上位から末端へ直接つなぐ見せかけの線を作らない。既存の自由配置・物理演算・手前奥の深度操作を維持する。

受け入れ条件:

- 3段階の実経路は中間ノードとそれぞれの接続を表示する。
- 同じ記録の異なる分類所属は両方表示し、同一所属の重複だけ拒否する。
- 共有する分類ノードと親子接続は重複させない。
- 根拠と推定・確定の区別、読取失敗時の表示を維持する。
- 画面監査と自動ブラウザー設定はPCの1280×720だけを対象にする。

元の画像による星空の意匠は維持し、今回の範囲は実経路への結線と誤表示防止に限定する。データ移行は不要。表示コードと読取投影を一緒に取消可能。
