# 検索候補の現在性と安全な再利用

実保存先の合成関係の確認中、検索が古い資産候補の識別子を参照して内部エラーになった。旧版を公開して回避せず、現行かつ共有可能な候補だけを順位付けと関係展開に使用する。

受け入れ条件:

- 古い資産を含む候補集合でも検索が失敗しない。
- 古い版・非公開記録・他の所有者を結果に出さない。
- 現行の根拠付き関係と出典の参照を維持する。
- 失敗する再現テストと、混在候補の回帰テストを追加する。

DBの変更・モデル比較・速度比較は不要。読取りコードとテストだけを修正し、正式版へ反映後に同じ合成記録を一度取得して確認する。コードの取消で戻せ、保存データは変更しない。
