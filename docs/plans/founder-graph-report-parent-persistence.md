# Founder Graph レポート親版の保存検証 計画

最終検証日: 2026-09-23

## 要望 / ゴール / 成功指標

要望: ローカルのレポート改訂を保存するとき、親版への参照が実在し、同じ利用者のレポートであることを確認する。

ゴール: 存在しない親版または別の種類の記録を親として保存できず、既存の8章レポート保存契約を壊さない。

成功指標: メモリ保存とNeo4j互換保存のどちらも、親版がない改訂版を保存前に拒否し、正しい親版を持つ改訂版は保存できる。

## ユーザーストーリーと受け入れ条件

### US-RPP-01 改訂版の親を確認する

As a 単独Founder, I want レポート改訂版を正しい親版へ結び付けて保存したい, so that 旧版との比較と追跡を誤らない。

Given: ローカル保存先に8章レポートが存在する、または親版IDが存在しない。

When: 親版IDを持つ新しい8章レポートを保存する。

Then: 親版が同じ利用者のReportVersionなら保存され、存在しない場合または別種類の場合は保存も監査記録も作られない。
