# Issue #65 unit economics 契約計画
最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標
値付け、変動費、CAC、retention、固定費、capacity、期間からbase/upside/downsideの決定的local計算を返す。通貨・期間の不整合、0除算、負margin、欠損をエラーとして観測できる。

## ユーザーストーリーと受け入れ条件
### US-65-01
As a 起業を検討する利用者, I want 採算前提を比較したい, so that仮説と確定値を混同せず判断できる。
Given: 同一通貨・同一期間単位の3シナリオを入力する
When: local calculatorを実行する
Then: 売上、変動費、限界利益、限界利益率、CAC回収単位、損益分岐販売量、営業利益を決定式で返す。
### US-65-02
As a 利用者, I want 不正な前提を止めたい, so that誤った財務判断を避けられる。
Given: 価格0、負margin、通貨混在、capacity超過、期間欠損の入力がある
When: calculatorを実行する
Then: 会計・税務・融資判断をせず、原因を示す入力エラーを返す。

## スコープ外
- 税務、消費税、減価償却、会計仕訳、融資審査、投資助言。
- 外部会計/金融サービス、実課金、個人情報送信、UI/App.jsx。

## ADR
| 判断 | 選択と理由 | 却下案と理由 | 結果 |
|---|---|---|---|
| ADR-65-01 | `Decimal`と通貨付き金額を使うlocal calculatorに限定する | float、外部会計API、AI推定は再現性または外部送信境界を満たさないため却下 | 入力と計算式をテストで固定する |
| ADR-65-02 | 3シナリオを明示入力し、未決の税・会計行を0円補完しない | AIが利益・融資可能性を断定する案は誤認を招くため却下 | 保証しない注記を計算結果に含める |
