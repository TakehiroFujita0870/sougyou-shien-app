# ファイル取込UI計画

最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標

> ファイルアップロード、解析状態、再試行、新版、削除確認の独立UIを実装する。

ゴールは、本人の資料の取込状態をローカルfake adapter越しに管理できる独立コンポーネントを作ることです。

成功指標は、対応外・上限超過・失敗・再試行・新版・削除確認を単体テストとStorybookのdesktop/mobile/a11y設定で再現することです。

## ユーザーストーリーと受け入れ条件

### US-1

As a 資料を登録するユーザー, I want 対応形式と解析状態を確認したい, so that 検索可能になる条件を判断できる。

Given: PDF、DOCX、TXT、CSVの候補
When: fake repositoryへ登録する
Then: 対応外と25 MiB超過は理由付きで拒否され、対応ファイルは解析中として表示される

### US-2

As a 解析に失敗したユーザー, I want 再試行したい, so that 修正済みの資料を再び処理できる。

Given: 失敗状態の資料
When: 再試行を選ぶ
Then: fake repositoryの再試行後状態が一覧へ反映される

### US-3

As a 資料を更新または削除するユーザー, I want 新版と削除確認を管理したい, so that 古い資料を検索対象から外せる。

Given: 既存の資料
When: 新版を追加または削除を確認する
Then: 版番号が増加するか、削除済みとして表示される
