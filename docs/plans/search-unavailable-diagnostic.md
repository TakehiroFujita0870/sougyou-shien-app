# 検索失敗を秘密情報なしに診断する計画

## 要望 / ゴール / 成功指標
実際の検索503が起きたが、現行ログから原因を特定できない。保存内容を記録せず例外の種類だけを残す。

## 受け入れ条件
Given: 読み取りが利用不能の例外になる。
When: MCP境界で安全な利用不能応答に変換する。
Then: 固定のログ文と上限付きの例外クラス名だけを残し、入力、所有者、鍵、例外本文、スタックを記録しない。HTTP応答は維持する。

## スコープ外
- 速度比較、別モデル、待ち時間延長、保存データ変更、再起動試験。

## タスク
| 成果物 | 完了判定 | 不確実性 |
| --- | --- | --- |
| 秘密情報なしの診断記録 | 検査: 機密文字列を例外・入力に含めてもクラス名だけが記録され、応答が同じ | 既知 |

## ADR
例外の種類を最大4段階記録する。却下: 例外本文や全スタックの記録は個人情報を含み得るため使わない。
