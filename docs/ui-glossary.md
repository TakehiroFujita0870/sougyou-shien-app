# UI用語集

| 正式表記 | 用途 | 禁止・置換 |
|---|---|---|
| Home | 会話と最初の入力を行う主要surface | Dashboard、トップへ |
| Project | 事業のタネを扱う主要surface | Ideas、案件 |
| Knowledge | 個人資料と調査根拠を扱う主要surface | Library、資料庫 |
| あなたの情報 | 利用者プロフィール | Account、プロフィール（画面見出しでは使わない） |
| プラン | Free/Standardの契約境界 | Subscription（利用者向け文言） |
| 準備中 | Proなど未提供機能の状態 | Coming soon（利用者向け文言） |

許可するpage eyebrowは `HOME`、`PROJECT`、`KNOWLEDGE`。top-level navはHome / Project / Knowledgeの3項目だけとする。
