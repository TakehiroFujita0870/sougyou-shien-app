# Kadode PRD v0.2（SDD・実装前）

最終更新: 2026-08-09

## 問題と成功

対象は、起業を考え始めた人と複数案を比較する起業経験者です。課題は、本人の経験・制約が対話へ蓄積されないこと、アイデアが会話に埋もれること、公開情報・特許・手元資料・過去判断を分けて調べる負担、AIが同じ助言を繰り返すことです。

成功状態は、ユーザーが「あなたの情報」を管理し、対話からアイデア仮説カードを作り、根拠付きの横断調査でカードを更新し、判断と理由を次回の対話へ引き継げることです。

## 初回リリースの体験

1. AIとの初回対話で、経験、得意分野、関心、使える時間、資金、避けたい条件を含む「あなたの情報」を作る。
2. 対話中の着想をアイデアストックへ保存し、編集可能なアイデア仮説カードへ育てる。
3. カードから「市場の見込み」「競合との違い」「攻めどころの特定」を開始する。フレームワーク名は補助説明に留める。
4. Web、特許、自分の資料、過去の意思決定を選んで横断調査する。
5. レポートの出典とAIの推論を区別し、カードの更新案をユーザーが確定する。
6. 採用、保留、却下と理由を記録し、次回に同種論点が出たとき前回判断との差分を示す。

## プラン

- Free: 軽量モデル、Thinking Effortなし、手動調査の利用上限あり。
- Standard: 980円/月、許可モデルから選択可能、既定は`gpt-5.6-terra`、Freeより大きい利用上限。
- Pro: 2980円/月の構想。定期深掘り調査とメール配信は初回リリースに含めず、利用量と原価の蓄積後に再計画する。

モデルID、更新、廃止対応は[モデル・APIライフサイクル](../operations/model-lifecycle.md)を正本とします。

## MVPスコープ

- 認証とowner-based RLS。
- 「あなたの情報」の作成、閲覧、更新、削除。
- 対話、アイデアストック、編集可能なアイデア仮説カード。
- PC・スマホ対応とPCの主要キーボード操作。
- 手動のWeb・特許・個人資料・意思決定横断調査。
- 出典付きレポートと意思決定履歴。
- Free/Standardの利用上限とモデル選択。
- ユーザー所有データのエクスポートと削除要求。
- X投稿はAI広報部が下書きを作り、CEO承認後に人が投稿する。

## 受入基準

| ID | 受入基準 |
|---|---|
| AC-01 | 初回対話を中断・再開でき、確定した「あなたの情報」を後から編集できる |
| AC-02 | 対話から保存したアイデアが本人のストックだけに表示される |
| AC-03 | 仮説カードの修正内容がユーザー確認後に保存される |
| AC-04 | 横断調査は選択したソースだけを使い、主張から原典へ到達できる |
| AC-05 | 別ユーザーのプロフィール、資料、断片、検索結果、判断記録を取得できない |
| AC-06 | 過去と似た論点には前回判断と今回変わった点を表示する |
| AC-07 | 削除済み資料は原本、抽出本文、埋め込みの全てが検索対象から外れる |
| AC-08 | FreeはThinking Effortを使わず、Standardは許可モデルから選べる |
| AC-09 | 主要フローをPCとスマホで完了でき、PCではキーボードだけでも操作できる |
| AC-10 | X投稿は下書き保存までで止まり、自動投稿APIを呼ばない |

横断調査の詳細な受け入れ条件、データ境界、ADRは[横断調査・個人ナレッジ・意思決定記憶 計画](research-memory-plan.md)を正本とします。

## 非目標

- 起業成功、特許性、新規性、非侵害の保証。
- 融資、補助金、法律、税務の代理判断・申請。
- Proの定期調査とメール配信。
- Xへの自動投稿。
- AIによる無承認の契約、課金開始、個人情報送信、外部公開。
- 固定Stageと通過ゲートによるユーザー体験の強制。

## CEO決裁が必要な境界

- 外部公開、支出、契約、法務判断、実ユーザーの個人情報を含む外部AI送信。
- Web・特許・埋め込みサービスの有償契約と本番APIキー設定。
- Free/Standardの具体的な利用上限と保存上限。
