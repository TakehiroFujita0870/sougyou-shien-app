# Kadode PRD v0.1（SDD・実装前）

## 問題と成功

対象は、独立を考える会社員と複数案を扱う連続起業家です。課題は、対話AIが迎合しやすいこと、案の死因と判断が失われること、検証前に雰囲気で決めることです。成功は「1案が一次検証結果を持ち、承認・却下・保留のDecision Recordを得る」卒業状態です。

## 非目標

起業成功の保証、融資・補助金申請代理、法律・税務助言、SNS自動投稿、滞在時間最大化、無人の開発・判定ループは行いません。

## MVPスコープ

1. 認証済み利用者がアイデアとペイン一行を登録する。
2. Stage 0〜4の成果物をMarkdown構造で保存し、Stage 1では起案と別の反証実行を要求する。
3. Stage 1で死因3件・根拠URL、Stage 2で品質ゲート、Stage 4で理由必須の決裁を検査する。
4. graveyard検索、全量Markdown+JSONエクスポート、即時削除要求、匿名統計オプトインを提供する。

## 受入基準

| ID | 受入基準 |
|---|---|
| AC-01 | 同一実行IDでStage 0とStage 1を完了できない |
| AC-02 | Stage 1は根拠URL付き死因3件なしに通過しない |
| AC-03 | Stage 2は15 URL・10定量根拠・必須節なしに通過しない |
| AC-04 | Decision Recordは分類と理由なしに確定しない |
| AC-05 | 利用者は自身の全データをMarkdown+JSONで取得できる |
| AC-06 | 匿名統計利用は既定OFFで、撤回可能 |
| AC-07 | X下書きはローカル保存のみで投稿APIを持たない |
