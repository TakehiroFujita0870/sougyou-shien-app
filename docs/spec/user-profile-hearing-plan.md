# 初回ヒアリング「あなたの情報」計画

最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標

要望: 初回アクセス時にAI対話風ヒアリングを開始し、経験、得意分野、関心、時間、資金、避けたい条件を中断・再開・編集できるようにする。

ゴール: 外部APIなしで、利用者が自分の情報を段階的に保存・編集できる。

成功指標: 初回、再開、完了後編集、入力検証、保存失敗を自動テストとStorybookで観測できる。

## ユーザーストーリーと受け入れ条件

### US-1 初回入力
As a 初めて使う利用者, I want 質問に一つずつ回答したい, so that 考えを整理できる。

Given: 保存済みプロフィールがない
When: 初回画面を開き回答を送信する
Then: 経験から順に六つの質問が表示される。

### US-2 中断と再開
As a 入力途中の利用者, I want 続きから再開したい, so that 回答をやり直さずに済む。

Given: 途中の回答と質問番号が保存されている
When: ヒアリングを再度開く
Then: 保存済みの質問番号と回答が表示される。

### US-3 完了後の編集
As a 完了した利用者, I want 設定画面から回答を更新したい, so that 状況の変化を反映できる。

Given: 六つの回答が完了している
When: 「あなたの情報を更新」を開き項目を選ぶ
Then: 選んだ項目の回答を変更して保存できる。

### US-4 操作と失敗表示
As a キーボード利用者, I want 送信と中断をキーボードで操作したい, so that PCでも速く入力できる。

Given: 回答欄にフォーカスがある
When: Enter、Shift+Enter、Escを押す
Then: Enterは送信、Shift+Enterは改行、Escはヒアリングを閉じる。
