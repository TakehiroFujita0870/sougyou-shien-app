# AI人格・導入文言 計画

最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標

要望: Dots.のAIを、利用者の経験と強みを起点に背中を押し、根拠のある反対意見も示し、低リスクな次の一歩を提案する人格として画面文言へ反映する。

ゴール: アイデア画面を開いた利用者が、否定から始める印象を受けず、自分の判断を保ったまま検討を始められる。

成功指標: 導入見出しと補助文が人格の3要素を示し、悪い既存文言とAI広報導線が静的UIから消え、現行4項目ナビゲーションのa11yテストが通る。

## ユーザーストーリーと受け入れ条件

### US-76-1

As a 起業を検討する利用者, I want 自分の経験を出発点にアイデアを検討したい, so that 考えが未整理でも最初の記録を始められる。

Given: 利用者がアイデア画面を開く

When: 導入見出しと補助文を読む

Then: 経験または強み、反対意見、低リスクな次の一歩を示す文言が表示される。

### US-76-2

As a AIの提案を読む利用者, I want 根拠とAIの見立てを区別したい, so that 提案を自分の判断と混同しない。

Given: 将来の画面が共通のAI文言を参照する

When: AI出力の表示文言を取得する

Then: 事実、AIの考え、未確認事項、利用者の判断を区別する定義を利用できる。

### US-76-3

As a キーボードまたは支援技術を使う利用者, I want 既存のワークスペース移動を保ったまま導入文言を読める, so that 操作方法を変えずに利用できる。

Given: アプリを初期表示する

When: ナビゲーションを確認する

Then: アイデア、横断調査、資料、設定の4項目だけが表示される。
