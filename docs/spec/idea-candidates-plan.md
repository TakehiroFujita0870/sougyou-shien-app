# アイデアストックと仮説カード計画

最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標

要望: 対話からアイデア候補を保存し、一覧、重複確認、編集可能な仮説カード、承認後の更新を提供する。

ゴール: 外部サービスへ送信せず、利用者が候補を保存して確認済みの変更だけを反映できる。

成功指標: 保存、重複、編集承認、保存失敗をテストし、PC/スマホStoryで表示できる。

## ユーザーストーリーと受け入れ条件

### US-1 候補を保存する
As a アイデアを考える利用者, I want 対話の案を候補として保存したい, so that 後で比較できる。

Given: タイトルと概要を入力している
When: 保存を実行する
Then: 候補が本人の一覧に表示される。

### US-2 重複を確認する
As a 候補を保存する利用者, I want 同じ題名の候補を確認したい, so that 同じ案を増やさない。

Given: 同じ正規化タイトルの候補がある
When: 保存を実行する
Then: 重複の候補が表示され、追加保存は行われない。

### US-3 仮説カードを更新する
As a 候補を育てる利用者, I want 編集案を確認してから反映したい, so that 意図しない変更を避けられる。

Given: 保存済みの候補を選んでいる
When: 編集案を承認する
Then: 承認したタイトル、概要、ペインがカードに表示される。

### US-4 失敗から回復する
As a 保存に失敗した利用者, I want 次の操作が分かる表示を見たい, so that 再試行できる。

Given: repositoryの保存が失敗する
When: 保存または承認を実行する
Then: 再試行を促すエラーが表示される。
