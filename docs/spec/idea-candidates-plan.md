# アイデアストックと仮説カード計画

最終検証日: 2026-08-09

## 要望 / ゴール / 成功指標

要望: 決定的なlocal/fake対話からアイデア候補を保存し、一覧、重複確認、編集可能な仮説カード、承認後の更新を提供する。

ゴール: 外部サービスへ送信せず、利用者が短い対話で対象者・困りごと・解決案を整理し、プレビューで確認した候補だけを保存できる。

成功指標: 会話の再開、保存、重複、編集承認、保存失敗、キーボード操作をテストし、PC/スマホ/空/会話準備済み/重複のStoryで表示できる。

## ユーザーストーリーと受け入れ条件

### US-1 候補を保存する
As a アイデアを考える利用者, I want 短い対話で案を言葉にして候補として保存したい, so that 後で比較できる。

Given: 対象者、困りごと、解決案の一部を会話へ入力している
When: local/fake応答を受け、プレビューから保存を実行する
Then: 外部送信なしに、候補が本人の一覧に表示される。

### US-2 対話を再開する
As a 考えを途中で止める利用者, I want 会話を再読込後に再開したい, so that 前の発言を失わない。

Given: local repositoryに会話履歴がある
When: ワークスペースを再表示する
Then: 時系列の発言と次の質問が表示される。

### US-3 重複を確認する
As a 候補を保存する利用者, I want 同じ題名の候補を確認したい, so that 同じ案を増やさない。

Given: 同じ正規化タイトルの候補がある
When: 保存を実行する
Then: 重複の候補が表示され、追加保存は行われない。

### US-4 仮説カードを更新する
As a 候補を育てる利用者, I want 編集案を確認してから反映したい, so that 意図しない変更を避けられる。

Given: 保存済みの候補を選んでいる
When: 編集案を承認する
Then: 承認したタイトル、概要、ペインがカードに表示される。

### US-5 失敗から回復する
As a 保存に失敗した利用者, I want 次の操作が分かる表示を見たい, so that 再試行できる。

Given: repositoryの保存が失敗する
When: 保存または承認を実行する
Then: 再試行を促すエラーが表示される。

## ADR

| 判断 | 選択と理由 | 却下案と理由 | 結果 |
| --- | --- | --- | --- |
| 保存API | 非同期repositoryをlocal/fake実装で提供する | Supabase直結は認証未設定のため却下 | release-gate #31で同一APIを実サービスadapterへ置換する |
| 更新 | 編集案を一時状態に置き承認ボタンで保存する | 入力ごとの自動保存は意図しない変更を残すため却下 | 承認済みの値だけをカードに反映する |
| 会話応答 | 入力済みの三要素を決定的に走査し、最初の不足項目を質問する | 外部LLMは個人情報送信と鍵設定を伴うため却下 | 実API adapterへ置換可能な純粋関数にする |
