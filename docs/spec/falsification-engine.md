# Dots. 仮説検証・調査支援仕様 v0.2

最終更新: 2026-08-09

## 目的

ユーザーの案を無条件に肯定せず、反対材料も含む根拠を示し、本人がアイデア仮説カードを更新できるようにします。固定Stageや通過ゲートは使わず、ユーザーが戻る・保留する・調べ直す操作を選べます。

## ユーザー向け機能名

| 内部で使う考え方 | 画面上の名称 |
|---|---|
| 市場性・規模・成長性 | 市場の見込み |
| 競合分析・代替手段 | 競合との違い |
| SWOT | 攻めどころの特定 |
| 反証・リスク分析 | うまくいかない理由を探す |
| Decision Record | 今回の判断 |

専門用語は詳細説明で補助し、主要ボタンと見出しには日常語を使います。

## 入出力

入力は「あなたの情報」、アイデア仮説カード、ユーザーが選択した調査ソース、過去の意思決定です。出力は事実、AIの推論、反対材料、未確認事項、カードの更新案、出典です。

ユーザーが更新案を確認するまで仮説カードを上書きしません。判断は採用・保留・却下と自由記述の理由を保存し、後の判断が前の判断を置き換える場合は継承関係を記録します。

## 調査品質

- 主張ごとにWeb URL、特許公開番号、ファイルのページ、意思決定IDの一つを関連付けます。
- 検索で見つからなかったことを、不存在の証明として表現しません。
- 過去に解決した指摘は前回判断を添えて表示し、新しい根拠または前提変化がなければ繰り返しを抑えます。
- 新しい根拠がある場合は、過去判断を隠さず再検討候補として表示します。
- 特許調査は先行技術候補の探索であり、特許性・新規性・侵害有無を判断しません。

横断検索、データ隔離、ファイル取込、特許ソースは[横断調査・個人ナレッジ・意思決定記憶 計画](research-memory-plan.md)を参照します。

## データ境界

プロフィール、アイデア、アップロード資料、抽出本文、埋め込み、調査履歴、意思決定はユーザー所有です。匿名統計の二次利用は独立したオプトインにし、既定をOFFとします。実ユーザーデータの外部AI送信はCEO決裁とユーザーへの送信対象表示が完了するまで行いません。

## 非目標

起業成功の保証、法律・税務判断、特許鑑定、無人の連続実行、X自動投稿は扱いません。
