# Dots ChatGPTプラグインの表示素材

このフォルダーは、Dotsの個人用ChatGPTプラグインの配布元です。`assets/dots-icon.png` は利用者が指定したDotsの画像から、上部の余分な見出しを除き、白背景にした正方形のアイコンです。画像内には星座状の印と `Dots.` の文字だけを残します。

`plugin.json` は表示名を `Dots`、開発者を `Takehiro Fujita`、説明文を日本語に設定します。`.app.json` は通常利用のDots接続を参照します。架空データ専用接続は独立して残し、この配布物には認証情報や実データを含めません。

2026-09-25に、既存の開発用プラグインの更新版（1.0.1）と、新しい個人用プラグイン（1.0.0）へ同じ画像を含む配布物を登録しました。個人用プラグインの識別子は `plugins_6ab5cfbd21b481919509d03026560f1c` です。

2026-09-26の読み取り専用API確認では、この個人用プラグインの現行登録はバージョン1.0.4でした。API上の現行説明文は日本語で、開発者名は `Takehiro Fujita` です。配布元にも `assets/dots-icon.png` があり、`plugin.json` の `composerIcon` と `logo` はこの画像を参照しています。

この確認は登録メタデータと配布物を対象としたもので、ChatGPT画面上の表示が一致することを示すものではありません。開発者表示は `App developer` と見える状態が報告されており、指定アイコンも画面上で反映されたか未確認です。画面表示が確認できるまでは、表示上の反映を完了扱いにしません。

2026-09-26に1.0.5へ更新し、下書き保存→内部検索→調査許諾→ChatGPT調査→8観点概要→根拠付き関係→訂正・再利用の会話手順を登録しました。API read-backで手順の完全一致、説明・作者・アイコン参照・通常接続先の保持、PRIVATEの維持を確認済みです。登録版は `pluginrel_6ab761c71ea08191bd99c6fba7ff6884`。これは実会話で全手順が動作した証明ではなく、実会話受入は別途必要です。

同日の1.0.5詳細画面では日本語説明・Takehiro Fujita・通常接続済み・スキル1件を確認しました。ただし画面のプラグインアイコンは青い既定図形のままで、指定画像との不一致が残っています。依存アプリの詳細画面は別画面で、作者表示がApp developerです。配布ファイルやAPI上のアイコン参照が正しいことと、画面上の反映を分けて扱います。
